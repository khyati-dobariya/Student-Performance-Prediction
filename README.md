Student Performance Prediction

Project Overview

This is a Machine Learning project that predicts students' mathematics scores based on different student-related features.

Dataset

Students Performance Dataset containing information about:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Pickle

Machine Learning Models

- Linear Regression
- Random Forest Regression

Project Workflow

1. Data Loading
2. Data Preprocessing
3. Feature Encoding
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Model Comparison
8. Model Saving and Loading
9. Sample Prediction

Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score

Project Files

- Student_Performance_prediction.ipynb
- StudentsPerformance.csv
- student_performance_model.pkl

How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Keep the CSV file in the correct working directory.
5. Run the notebook cells.
